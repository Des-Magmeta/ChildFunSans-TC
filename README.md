## 項目簡介
Stick 因筆形像筆桿一樣以直線設計<span lang="zh-TW">，</span>而被視爲一款既可愛調皮<span lang="zh-TW">，</span>亦有田園寫意風格的字型<span lang="zh-TW">，</span>在設計領域廣受應用<span lang="zh-TW">。</span>然而原始字體 Stick 是為日文而設<span lang="zh-TW">，</span>漢字部份以日本使用的字形爲基準<span lang="zh-TW">，</span>且只支援 Adobe-Japan1-3 範圍的漢字<span lang="zh-TW">，</span>仍缺部分常用字<span lang="zh-TW">，</span>無法滿足日常繁體中文應用需求<span lang="zh-TW">。</span>故本人計劃基於 Fontworks 出品的日文字型 Stick 增補<span lang="zh-TW">、</span>調整字形<span lang="zh-TW">，</span>並編輯<span lang="zh-TW">、</span>適當增加 OpenType 特性<span lang="zh-TW">，</span>以滿足繁體中文的使用需求<span lang="zh-TW">。</span>
## 總體計劃
考慮到本字型的部分筆形具有一定手寫感<span lang="zh-TW">，</span>本字型計劃發佈現代字形版本<span lang="zh-TW">，</span>採用折中印刷字形<span lang="zh-TW">，</span>在傳統字形基礎上<span lang="zh-TW">，</span>兼顧當代慣用部件寫法<span lang="zh-TW">。</span>具體規則詳見[「遊趣體」繁體版設計計劃及部件細則](https://github.com/Des-Magmeta/ChildFunSans-TC/blob/main/Docs/Rule_Components.md)<span lang="zh-TW">。</span>

## 注意事項
 1. 本人並非專業設計師<span lang="zh-TW">，</span>並未考慮設計美感<span lang="zh-TW">，</span>故部分字形可能不美觀<span lang="zh-TW">，</span>後補字與原版可能略有違和感<span lang="zh-TW">，</span>且在新補字元中部分字的輪廓曲線會有毛刺<span lang="zh-TW">。</span>此外由於時間倉促<span lang="zh-TW">，</span>並沒有多餘的時間細修<span lang="zh-TW">，</span>部分字的部件拼接比較生硬<span lang="zh-TW">。</span>如有字形優化建議<span lang="zh-TW">，</span>請在 [Issue #2](https://github.com/Des-Magmeta/ChildFunSans-TC/issues/2) 提出<span lang="zh-TW">。</span>如需請求添加目標範圍以外的字元<span lang="zh-TW">，</span>請在 [Issue #1](https://github.com/Des-Magmeta/ChildFunSans-TC/issues/1) 提出<span lang="zh-TW">，</span>**不要另外新建 Issue 串<span lang="zh-TW">，</span>以便於整理<span lang="zh-TW">。</span>**
 2. 此字型採用折中印刷體（偏現代字形）<span lang="zh-TW">，</span>可能無法滿足傳統字形愛好者需求<span lang="zh-TW">，</span>如需使用傳統字形版本<span lang="zh-TW">，</span>請移步[「傳趣體」](https://github.com/Steve-Yuu/Chuanqu)<span lang="zh-TW">。</span>  
 3.「遊趣體」支持 Unicode 變體序列（Unicode Variation Sequences, UVS）<span lang="zh-TW">，</span>用於彎引號`“‘’”`寬度和全形標點符號`，．、。：；！？`位置的選擇<span lang="zh-TW">，</span>支援變體序列的字元和所搭配的選擇符詳見[「遊趣體」變體序列一覽表](https://github.com/Des-Magmeta/ChildFunSans/Docs/Feature_UVS.md)<span lang="zh-TW">。</span>**WPS Office<span lang="zh-TW">、</span>PowerPoint (Microsoft 365) 軟體不支援此特性**<span lang="zh-TW">，</span>使用時需留意<span lang="zh-TW">。</span> 
 4. 部分軟體（如 PowerPoint 365）中<span lang="zh-TW">，</span>使用該字型可能會出現豎排文本顯示異常的問題<span lang="zh-TW">。</span>
 5. 此字型面向繁體中文用戶<span lang="zh-TW">，</span>如需使用簡體中文版<span lang="zh-TW">，</span>請移步[「遊趣體」簡體版](https://github.com/Des-Magmeta/ChildFunSans)<span lang="zh-TW">。</span>
