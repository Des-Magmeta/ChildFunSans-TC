# 「遊趣體」繁體版設計計劃（部件對照版）
此文檔為繁體版專案成立前所編寫，後因一部分部件細則發生改動而與原始計劃差異較大，內容與現行規則表相比部分內容有明顯差異。  
該專案目前採用折中印刷體筆形，在傳統字形基礎上，兼顧當代慣用部件寫法。此表亦可供製作者在改作傳統字形時參考。
## 總體計劃
 - 漢字部件的選用盡可能使用原版／簡體版既有的字形，如「辛」上部在原始授權字型 Stick 中均作「亠」，故 TC 版仍沿用「亠」形；
 - CL、MN 橫排和直排均采用置中標點，蝌蚪引號采用西文式（比例寬度）。 
 - 部分部件的字形視為設計特性，不做改動，如「穴」「令」「瓦」等字；
 - 同一部件的不同設計形態並不構成衝突，如「四」「穴」與「夋」「甚」內部的「八／儿」等。
